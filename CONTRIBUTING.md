## Contributing

The repository is maintained as an archival record of the project and is therefore not open for external contributions.
Contribution are only allowed by the authors Sarah Glass, Petra Merten, Torsten Brinkmann or Volkan Filiz. 

## Reuse

You are welcome to use the code, analysis, and materials in this repository for your own work.

If you build upon this work, please cite this repository appropriately.

## Derivative work

If you would like to extend or modify the work, please create your own repository or fork and develop your work there.
